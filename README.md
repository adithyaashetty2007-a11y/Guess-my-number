# Guess My Number 🎯

A simple number guessing game built using HTML, CSS, and JavaScript.

## Features
- Guess a secret number between 1 and 20.
- Get feedback on whether your guess is too high or too low.
- Track your score.
- Keep track of your high score.
- Restart the game and play again.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Enter a number between 1 and 20.
4. Click Check to submit your guess.
5. Click Again to restart the game.
